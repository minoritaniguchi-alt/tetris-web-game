# テトリス Webゲーム - 要件定義書

## 1. 機能要件

### 1.1 ゲームコア機能

#### 1.1.1 テトリミノ（ブロック）
- 7種類の標準テトリミノを実装
  - I-piece (水色)
  - O-piece (黄色)
  - T-piece (紫)
  - S-piece (緑)
  - Z-piece (赤)
  - J-piece (青)
  - L-piece (オレンジ)
- ランダムな順序でテトリミノを生成
- 次のテトリミノをプレビュー表示

#### 1.1.2 ゲームボード
- 標準サイズ: 10列 × 20行
- ボード境界の衝突判定
- 既存ブロックとの衝突判定

#### 1.1.3 操作機能
- 左移動: 左矢印キー または Aキー
- 右移動: 右矢印キー または Dキー
- 回転: 上矢印キー または Wキー または スペースキー
- ソフトドロップ（加速落下）: 下矢印キー または Sキー
- ハードドロップ（即座に落下）: スペースキー
- 一時停止: Pキー または Escキー

#### 1.1.4 ゲームロジック
- テトリミノの自動落下
- ライン完成時の消去
- 消去後の上部ブロック落下
- レベルアップによる落下速度の増加
- ゲームオーバー判定（新しいブロックが配置できない場合）

### 1.2 スコアリングシステム

#### 1.2.1 得点計算
- 1ライン消去: 100点 × レベル
- 2ライン同時消去: 300点 × レベル
- 3ライン同時消去: 500点 × レベル
- 4ライン同時消去（テトリス）: 800点 × レベル
- ソフトドロップ: 1点/セル
- ハードドロップ: 2点/セル

#### 1.2.2 レベルシステム
- 初期レベル: 1
- レベルアップ条件: 10ライン消去ごと
- 最大レベル: 15
- レベルに応じた落下速度調整

#### 1.2.3 統計情報
- 現在のスコア
- 現在のレベル
- 消去したライン数
- ハイスコア（ローカルストレージに保存）

### 1.3 UI/UX機能

#### 1.3.1 ゲーム画面
- ゲームボード表示エリア
- 次のテトリミノプレビューエリア
- スコア・レベル・ライン数表示エリア
- ゲームコントロールボタン
  - 開始/再開ボタン
  - 一時停止ボタン
  - リセットボタン

#### 1.3.2 ビジュアルフィードバック
- ブロックのカラフルな表示
- ライン消去時のアニメーション
- ゲームオーバー時の表示
- レベルアップ時の通知

#### 1.3.3 サウンドエフェクト（オプション）
- ブロック移動音
- ブロック回転音
- ライン消去音
- ゲームオーバー音
- 音量調整機能
- ミュート機能

### 1.4 データ永続化

#### 1.4.1 ローカルストレージ
- ハイスコアの保存
- ゲーム設定の保存
  - サウンドON/OFF
  - 音量設定
- 中断したゲームの状態保存（オプション）

## 2. 非機能要件

### 2.1 パフォーマンス要件
- フレームレート: 60FPS以上を維持
- 初期ロード時間: 3秒以内
- 操作の入力遅延: 50ms以内
- メモリ使用量: 50MB以内

### 2.2 互換性要件

#### 2.2.1 ブラウザサポート
- Google Chrome (最新版および1つ前のバージョン)
- Mozilla Firefox (最新版および1つ前のバージョン)
- Safari (最新版および1つ前のバージョン)
- Microsoft Edge (最新版および1つ前のバージョン)

#### 2.2.2 画面サイズ対応
- デスクトップ: 1920x1080以上
- タブレット: 768x1024以上（横・縦）
- モバイル: 375x667以上（フェーズ2以降）

### 2.3 ユーザビリティ要件
- 初回プレイ時の簡単な操作説明表示
- 直感的なUI配置
- アクセシビリティ対応
  - キーボード操作のみでゲーム可能
  - 色覚異常者向けの配色オプション（オプション）

### 2.4 セキュリティ要件
- XSS攻撃対策
- ローカルストレージデータの検証

### 2.5 保守性要件
- モジュール化されたコード設計
- コメント・ドキュメントの整備
- ESLint/Prettierによるコード規約準拠
- ユニットテストのカバレッジ80%以上

## 3. 制約条件

### 3.1 技術的制約
- クライアントサイドのみで動作（サーバー不要）
- 外部ライブラリの最小化
- バンドルサイズ: 500KB以内

### 3.2 ビジネス的制約
- オープンソースとして公開可能なライセンス
- 商用利用可能なアセットのみ使用

## 4. 受け入れ基準

### 4.1 機能面
- すべての基本機能が正常に動作すること
- ゲームロジックが正確であること
- スコア計算が正確であること

### 4.2 品質面
- 主要ブラウザでバグなく動作すること
- パフォーマンス要件を満たすこと
- ユニットテストがすべてパスすること

### 4.3 ユーザビリティ
- 5人のテストユーザーが説明なしでゲームを開始できること
- 操作に違和感がないこと

## 5. 優先順位

### P0（必須）
- 基本的なゲームロジック
- 7種類のテトリミノ
- スコアリングシステム
- ゲームオーバー判定

### P1（高優先度）
- 次のブロックプレビュー
- ハイスコア保存
- 一時停止機能
- レベルシステム

### P2（中優先度）
- サウンドエフェクト
- ビジュアルエフェクト
- ゲーム状態保存

### P3（低優先度）
- タッチ操作対応
- 色覚異常対応
- 追加のゲームモード
