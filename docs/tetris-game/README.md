## ドキュメントの読み方

### 初めての方
1. まず **SOW** を読んでプロジェクト全体を把握
2. **要件定義書** で何を作るかを理解
3. **技術仕様書** でどのように作るかを理解
4. **WBS** で作業の詳細を確認

### 開発者向け
- 実装前: **技術仕様書** のクラス設計とアルゴリズムを参照
- タスク確認: **WBS** で担当タスクを確認
- 要件確認: **要件定義書** で機能仕様を確認

### プロジェクトマネージャー向け
- 進捗管理: **WBS** のチェックリストで進捗追跡
- リスク管理: **SOW** のリスク管理セクションを参照
- 品質管理: **要件定義書** の受け入れ基準を確認

## プロジェクト概要

### 目的
モダンなWeb技術を使用して、クラシックなテトリスゲームをブラウザ上で動作するWebアプリケーションとして実装する。

### 主要技術スタック
- HTML5
- CSS3
- JavaScript (ES6+)
- Canvas API
- Jest (テスト)
- Webpack/Vite (ビルド)

### 主要機能
- 7種類のテトリミノ
- スコアリングシステム
- レベルシステム
- ローカルストレージによるデータ永続化
- レスポンシブデザイン
